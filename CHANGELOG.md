# Changelog

## 0.22.0
- One jar per Minecraft version: 1.20.6, 1.21.1, 1.21.4, 1.21.8, 1.21.10, 1.21.11, 26.1.2, 26.2 and 26.3. See [docs/VERSIONS.md](docs/VERSIONS.md).
- Works on 1.20.6 and 1.21.1: the maximum-health lookup and the item storage used by shop backups and duels no longer need a newer server.
- No feature changes.

## 0.21.0
- Web panel: new Ranks page (create, edit and delete ranks, prefix preview, permissions, inheritance, default rank, chat line).
- Web panel: new Teams page (list, filter, disband) and Anti X-ray page (level, worlds, options, height limits).
- Web panel, Players: give or remove a rank, give or take crate keys, reset stats.

## 0.20.0
- `/antixray` opens a screen that controls every anti X-ray setting, including the block lists.

## 0.19.0
- New feature: Anti X-ray (level 1 and 2, per world), built on Paper's own engine.

## 0.18.0
- Frozen players stay frozen across logout and restart. Larger web panel: dashboard, punishments, player tools.

Earlier versions were not published.
